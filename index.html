How I work with AI

I build AI-first, inside a workflow I designed and keep under version control. Every change starts as a plan I approve; tests come before code; on high-risk work a second model from another provider reviews the spec and the plan; and the rules that matter, like security checks, are enforced by hooks instead of remembered. I've also used Claude Code plan-first on client work. Agents write the code; I own the architecture, the plan, the trade-offs and what gets merged.

RunHub · runhub.uy

Every running race in Uruguay, in one place. The website is the easy part; the hard part is keeping the calendar complete and current with a few hours of work a week. Nothing is published until a person approves it. Fetching is SSRF-safe and every run has a cost cap.
